## How to Check What's Deployed

1. **Check GitHub Actions**: Go to your repo → Actions tab → See latest workflow run
2. **Check GitHub Pages**: Visit your GitHub Pages URL (usually `https://[username].github.io/widgetbook-test/`)
3. **Compare with local**: Run `cd widgetbook_app && flutter run -d chrome` to see local version

## Making Updates

1. **Add/Edit Widgets**: Edit files in `lib/widgets/`
2. **Add/Edit Stories**: Edit files in `widgetbook_app/lib/*_stories.dart`
3. **Test Locally**: `cd widgetbook_app && flutter run -d chrome`
4. **Deploy**: Push to `main` branch → Auto-deploys!
